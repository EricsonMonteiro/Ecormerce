1 - O protocolo OAuth 2.0 permite que um utilizador inicie sessão utilizando outra plataforma (Google, GitHub etc.) sem partilhar a sua palavra-passe.

Exemplos de fornecedores:

Google
GitHub
Facebook

Principais atores
Ator                                                   Papel
******************************************************************************
Proprietário do recurso (Resource Owner):              O utilizador
Cliente (Client):                                      A sua aplicação web
Servidor de autorização (Authorization Server):        OAuth Provider (Google, GitHub etc.)
Servidor de recursos (Resource Server):                API que armazena os dados do utilizador

2 - OAuth 2.0 Authorization Code Flow

******************************************************************************

Projeto 1

Implemente OAuth 2.0 em uma aplicação web utilizando JavaScript puro no frontend e PHP ou Python no backend, seguindo o Authorization Code Flow.

O sistema deve permitir autenticação através de um dos seguintes provedores OAuth: Google, Apple, Facebook

Utilize como referência o código do exemplo apresentado na aula prática com o login via GitHub.

A implementação deve incluir:

Redirecionamento do utilizador para o provedor OAuth.

Recepção do authorization code.

Troca do authorization code por access token no backend PHP.

Obtenção dos dados do utilizador autenticado.

Criação de sessão do utilizador na aplicação.

******************************************************************************

Apresentação na aula prática

Na aula prática, cada aluno deverá demonstrar o funcionamento da implementação OAuth 2.0.

Após obter o Access Token, o aluno deverá utilizar o comando curl no terminal para realizar uma requisição à API do provedor escolhido e apresentar os dados do utilizador autenticado.

A demonstração deve incluir:

Login através do provedor OAuth.

Obtenção do Authorization Code.

Troca do Authorization Code por Access Token.

Utilização do Access Token em uma requisição curl para obter os dados do utilizador.

******************************************************************************

Uso do ngrok

Para permitir o redirecionamento do provedor OAuth para a aplicação local, os alunos devem utilizar o ngrok para expor o servidor local à internet.

Exemplo:

ngrok http 80

A URL gerada pelo ngrok deverá ser utilizada como Redirect URI na configuração do provedor OAuth.

Vantagem pedagógica

Os alunos aprendem também:

APIs reais

OAuth com provedores externos

testes com curl

uso de ferramentas de desenvolvimento modernas

******************************************************************************

Objetivo do projeto

Este projeto demonstra a integração entre sistemas distribuídos através de protocolos web.
A aplicação desenvolvida irá comunicar com serviços externos de autenticação utilizando OAuth 2.0, um protocolo amplamente utilizado em arquiteturas distribuídas.
