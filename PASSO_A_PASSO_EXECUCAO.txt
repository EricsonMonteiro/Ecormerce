# GUIA DE EXECUÇÃO DO PROJETO E-COMMERCE

Este projeto atual contém apenas o frontend Next.js em `FrontEnd`.
O backend Python/FastAPI (`product_service-9000`) foi removido e não está mais presente no repositório.

---

## PASSO 1: Configurar e Rodar o Frontend (Next.js)

1. Abra um terminal na pasta raiz do projeto (`Ecomerce`).
2. Acesse a pasta do frontend:
   cd FrontEnd

3. Instale as dependências do Node.js:
   npm install

4. Configure as variáveis de ambiente:
   - Copie `.env.local.example` para `.env.local`.
   - Preencha as chaves necessárias de Google OAuth, Stripe e outras variáveis que o projeto usar.

5. Execute o servidor de desenvolvimento do frontend:
   npm run dev

6. Acesse o site no navegador em:
   http://localhost:3000

---

## PASSO 2: Rodar o Webhook do Stripe (Quando necessário)

1. Abra um segundo terminal.
2. Acesse a pasta do frontend:
   cd FrontEnd

3. Execute o script do Stripe:
   .\stripe-listen.bat

   Isso fará o encaminhamento dos eventos do Stripe para:
   http://localhost:3000/api/webhooks/stripe

---

## RESUMO DOS TERMINAIS QUE DEVEM FICAR ABERTOS:
- Terminal 1: Frontend Next.js (npm run dev na pasta `FrontEnd`)
- Terminal 2: Stripe CLI, se precisar testar pagamentos locais
